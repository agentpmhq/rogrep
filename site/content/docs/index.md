rogrep is a local search and analysis tool for coding-agent sessions. Start with [installation](/docs/installation/) and your [first sync](/docs/getting-started/), or jump to the [agent playbook](/docs/agents/).

## Choose a path

- **New to rogrep:** install it, sync, then learn conversations, exchanges, and turns.
- **Find past work:** use [search and facets](/docs/guides/searching/), then narrow with `find`, `show`, and `git`.
- **Configure an agent:** install the bundled skill and copy the [AGENTS.md snippet](/docs/agents/#agents.md-snippet).
- **Exact syntax:** use the generated [CLI reference](/docs/cli/) and canonical [query grammar](/docs/query-syntax/).

Everything runs against derived data on your machine. Source rollouts remain the durable truth.
