title: Provider discovery
description: See which coding-agent stores rogrep discovers.
---
rogrep discovers local stores for Claude Code, Codex, Cursor, Grok, Hermes, and OpenCode. Run `rogrep doctor` to see roots, readable files, parser health, and index status. Discovery is read-only. If a provider is absent, confirm it has written local sessions and inspect [configuration](/docs/guides/configuration/).
