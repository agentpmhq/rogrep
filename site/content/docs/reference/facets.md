title: Query facets
description: Structured filters available in rogrep queries.
---
Facets cover provider, project, conversation metadata, tools, files, Git and GitHub operations, dates, roles, visibility, and subagents. Unknown `key:value` tokens remain literal searchable text rather than disappearing. The exhaustive, grammar-synchronized list lives in [query syntax](/docs/query-syntax/).
